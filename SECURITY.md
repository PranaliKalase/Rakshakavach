# Security Policy for RAKSHKAVACH

## Safety Principles
1. **Decision Support Only**: AI outputs are strictly review signals and never issue final administrative actions or criminal accusations.
2. **Deny-by-Default Access Control**: All API endpoints and database access enforcement utilize Row-Level Security (RLS) and strict RBAC.
3. **No Secret Leakage**: Service-role keys must never be exposed to browser environments or client-side assets.

## Reporting Vulnerabilities
If you discover a security vulnerability within RAKSHKAVACH, please report it via confidential email or log an issue marked security in the repository issue tracker.
