# Product Requirements Document (PRD) — RAKSHKAVACH

## 1. Executive Summary
**RAKSHKAVACH** is an AI-powered MPLADS Verification & Trust Platform designed to assist district authorities, MPs, implementing agencies, monitoring officers, and ministry oversight bodies in ensuring transparent, data-driven, and verifiable project lifecycles.

## 2. Core Product Philosophy
- **AI ASSISTS.**
- **HUMANS VERIFY.**
- **AUTHORIZED OFFICERS DECIDE.**

## 3. Key Feature Modules
1. **Role-Based Dashboards**: Customized views for MP, District Authority, Implementing Agency, Monitoring Officer, Ministry, Admin, and Public.
2. **Project Lifecycle Management**: Recommendation ➔ Review ➔ Sanction/Rejection ➔ Agency Assignment ➔ Progress Updates ➔ Verification ➔ Completion ➔ Audit.
3. **AI Evidence & Anomaly Detection**: Rule engine + unsupervised Isolation Forest model + TF-IDF Cosine Similarity for potential project duplicate detection.
4. **Explainable AI & Anomaly Radar**: Clear human-readable breakdowns explaining why a project requires attention.
5. **Tamper-Evident Evidence Ledger**: Cryptographic SHA-256 hash chains verifying document and photo evidence integrity.
6. **Digital Audit Room**: Comprehensive digital case file output for complete project lifecycle transparency.
7. **Governance Copilot**: Permission-aware decision-support assistant with explicit source citations.
